## Objetivo
Desenvolver uma plataforma web para visualização de dados
hidrológicos e meteorológicos do município de Agudo, RS.

## Público
Moradores, Defesa Civil, agricultores, estudantes e gestores públicos.

## Primeira versão
- Nível atual do rio
- Cota de inundação
- Chuva acumulada
- Temperatura
- Tendência do nível
- Data e hora da atualização
- Fonte dos dados

## Tecnologias iniciais
- HTML
- CSS
- JavaScript
- JSON
- GitHub Pages

## Regras
- Todo dado deve apresentar fonte.
- Todo dado deve apresentar data e hora.
- Dados antigos devem ser identificados.
- O sistema não deve se apresentar como alerta oficial.
